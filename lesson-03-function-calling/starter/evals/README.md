# Lesson 03 evals у студентській копії

Ця довідка описує eval-частину завдання, а не наявність файлів у канонічному
starter. Каталог `starter/` містить лише байтово тотожну non-Markdown основу
Lesson 02; extraction evals успадковані, а tool-calling cases і runner потрібно
додати в `my-dev/lesson-03-function-calling/evals/` за
[roadmap](../../roadmap-code-guide.md).

З кореня репозиторію `yarn student:eval 03 openai` запускає offline recorded
cases студентської копії. Перевірте фактичний результат разом із
`yarn student:check 03 openai`; replay перевіряє datasets і scorer, але не є
live-запитом до OpenAI.
