# Lesson 02 — evals готового рішення

## Offline-перевірка

```powershell
# Команди виконуються з кореня репозиторію, де розташований package.json.
yarn eval:lesson02:solution
```

Вона перевіряє 5 dataset cases і scorer на записаних спостереженнях без мережі.
Очікуваний підсумок: `5/5` і `100.0%`.

## Live-перевірка реальної моделі

```powershell
yarn eval:lesson02:solution:live
```

Live mode використовує `OPENAI_MODEL_MAIN`, виконує 5 реальних extraction
запитів і може бути платним. Команда завершується помилкою, якщо success rate
нижчий за 80%.

Імена, дати та місця порівнюються без залежності від порядку. Summary
перевіряється за типом, довжиною та ключовими фактами, а не за повним збігом
рядка.
