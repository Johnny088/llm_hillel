# Lesson 02 — evals для starter

## Offline-перевірка без API key

```powershell
# Команди виконуються з кореня репозиторію, де розташований package.json.
yarn eval:lesson02
```

Вона використовує 5 синтетичних кейсів і записані результати. Очікуваний
підсумок після завершення starter — `5/5` і `100.0%`. Реального запиту до
OpenAI немає.

## Live-перевірка власної реалізації

```powershell
yarn eval:lesson02:live
```

Live mode працює лише після реалізації `extract()`, потребує кореневого `.env`,
виконує 5 реальних API-запитів і може бути платним. Exact string match для
summary не використовується.
