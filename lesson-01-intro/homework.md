# Домашнє завдання — Lesson 01 (OpenAI)

## Результат

Після підготовки через Промпт 1 реалізувати типізований одноразовий LLM-powered CLI-застосунок у `my-dev/lesson-01-intro/`, скопійованій зі `lesson-01-intro/starter/`. Застосунок використовує OpenAI Responses API без conversation state, інструментів та agent loop.

## Обов'язково

1. Реалізувати `loadEnvironment(env)` для `OPENAI_API_KEY` і
   `OPENAI_MODEL_FAST`: перевірити обидва значення та повернути лише дозволені
   поля без виведення секретів.
2. Реалізувати `readUserInput(args)` з об'єднанням аргументів, `trim()` і
   відхиленням порожнього вводу.
3. Реалізувати безпечне форматування HTTP, network і timeout errors без витоку
   provider body, заголовків або ключа.
4. Реалізувати `requestAnswer(...)` через `client.responses.create` з полями
   `model`, `instructions`, `input` і `store: false`.
5. Брати model ID лише з перевіреного environment, а відповідь — з
   `response.output_text`; відхиляти порожній текст.
6. Виводити надісланий текст, відповідь і фактичну модель, яку повернув OpenAI.
7. Замінити всі 14 `it.todo` повноцінними unit-тестами.
8. Не виконувати реальні API calls у unit-тестах: Responses client підміняється
   mock-об'єктом.
9. Не змінювати канонічні `starter/`, `solution/` або `dev/` і не додавати функції з наступних уроків.
10. Категорично не додавати `.env` або API key до Git чи матеріалів здачі.

## Перевірка

Промпт 1 готує гілку `lesson-01-intro`, копію `my-dev/lesson-01-intro/` та потрібні студентські команди. Якщо скриптів ще немає, він налаштує їх і запише точні назви у README студентської папки. З кореня репозиторію запускайте офлайн-команди, вказані там, щоб перевірити саме свою папку. Офлайн-перевірки не потребують API key. Не запускайте `test:lesson01`, `check:lesson01` або `dev:lesson01` як перевірку власної реалізації: ці канонічні команди націлені на `starter/` або `solution/`.

Після успішних офлайн-перевірок виконайте один контрольований ручний live smoke test на синтетичному запиті командою запуску власної папки, яку задокументував Промпт 1. Для цього налаштуйте локальний кореневий `.env` зі своїм `OPENAI_API_KEY` та доступним `OPENAI_MODEL_FAST`. Не надсилайте приватні дані. Якщо live-виклик недоступний, позначте його `NOT RUN`; mock-тест не є доказом live-роботи.

Здавайте роботу з гілки `lesson-01-intro`, надавши посилання на доступний fork, пряму адресу `my-dev/lesson-01-intro/` у цій гілці та SHA перевіреного commit. Merge request до основного репозиторію курсу не створюється. `.env` і ключі не додаються до Git.
