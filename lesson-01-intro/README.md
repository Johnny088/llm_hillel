# Lesson 01 — перший запит до OpenAI

> **Студентам курсу:** Почніть із [INSTRUCTION.md](../INSTRUCTION.md) – головної точки входу. Далі виконуйте маршрут зі [STUDENTS.md](../STUDENTS.md): Промпт 1 підготує гілку `lesson-01-intro` і папку `my-dev/lesson-01-intro/`. Працюйте лише у своїй папці; цей README містить довідковий запуск канонічного рішення.

У цій практиці консольна програма надсилає один текстовий запит до реальної
моделі OpenAI та показує її відповідь. Графічного інтерфейсу й вебсервера тут
немає: результат з'являється безпосередньо в PowerShell.

## Довідкова демонстрація канонічного solution

Цей приклад запускає еталон із `solution/` і призначений для демонстрації. Для студентської роботи використовуйте гілку та `my-dev/`, підготовлені Промптом 1.

### 1. Відкрити PowerShell у корені практичного репозиторію

```powershell
# Команди виконуються з кореня репозиторію, де розташований package.json.
```

Усі команди нижче виконуються саме з цієї папки. Yarn також знайде кореневий
`package.json`, якщо команда запущена з `lesson-01-intro`, `starter` або
`solution`, але назва команди все одно визначає, який варіант запускається.

### 2. Один раз установити залежності та створити `.env`

```powershell
yarn install --immutable
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
```

У файлі `.env` потрібно заповнити щонайменше два рядки:

```dotenv
OPENAI_API_KEY=ваш_ключ_OpenAI
OPENAI_MODEL_FAST=ідентифікатор_доступної_моделі
```

Замість пояснювального тексту після `=` вставляються справжні значення без
лапок і кутових дужок. Ключ створюється на сторінці
[OpenAI API keys](https://platform.openai.com/api-keys), а ідентифікатор моделі
обирається в [офіційному каталозі моделей](https://developers.openai.com/api/docs/models)
з урахуванням доступу конкретного API-акаунта. API key не можна надсилати
викладачу чи додавати до Git.

> Реальний виклик OpenAI може бути платним. Наявність підписки ChatGPT не
> означає наявність коштів в API-акаунті.

### 3. Запустити готове рішення

```powershell
yarn dev:lesson01:solution "Обчисли 37 * 19. Поверни лише число."
```

Програма спочатку покаже, що саме надсилається, потім дочекається OpenAI і
виведе відповідь. Форма успішного результату:

```text
📤 Надіслано:
Обчисли 37 * 19. Поверни лише число.
🎯 Налаштована модель: <значення OPENAI_MODEL_FAST>
⏳ Очікування відповіді OpenAI...

📝 Відповідь:
703

🤖 Фактична модель: <модель, зазначена OpenAI у відповіді>
```

Текст моделі може відрізнятися. Практика працює, якщо немає рядка з `❌`, після
`📝 Відповідь:` є непорожня відповідь, а в кінці показано фактичну модель.

## Студентська робота

Промпт 1 зі [STUDENTS.md](../STUDENTS.md) готує гілку `lesson-01-intro` і копіює starter до `my-dev/lesson-01-intro/`. Виконуйте завдання тільки у цій папці. Промпт 1 налаштує потрібні студентські команди, якщо їх ще немає, і запише точні команди до README вашої папки. Користуйтеся ними для тестів та запуску власного коду.

Наведені нижче команди запускають канонічні `starter/` або `solution/` і є довідковими:

| Команда                              | Що запускається      |
| ------------------------------------ | -------------------- |
| `yarn dev:lesson01:solution "текст"` | готовий `solution`   |
| `yarn dev:lesson01 "текст"`          | навчальний `starter` |

## Автоматична перевірка канонічного solution (довідка)

Ця перевірка не звертається до OpenAI та не витрачає кошти. Команда нижче перевіряє лише канонічний `solution/`, а не `my-dev/`. Для власного коду запускайте офлайн-команди, записані Промптом 1 у README студентської папки; для них API key не потрібен.

```powershell
yarn check:lesson01:solution
```

Команда перевіряє структуру репозиторію, форматування, типи, 14 unit-тестів
готового рішення, тести checkpoint-станів і production build. Успіх — усі
етапи завершилися без помилки та команда повернула PowerShell prompt.

## Якщо довідковий live-запуск не вдався

- `Потрібно задати: OPENAI_API_KEY` — ключ відсутній у кореневому `.env`.
- `Потрібно задати: OPENAI_MODEL_FAST` — не вказано ідентифікатор моделі.
- `HTTP 401` — ключ відхилено OpenAI.
- `HTTP 429` — вичерпано ліміт або немає доступного API-балансу.
- `Перевищено час очікування` — OpenAI не відповів за 30 секунд; запуск можна
  повторити.
