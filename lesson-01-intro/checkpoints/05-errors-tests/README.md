# Checkpoint 5 — безпечні помилки та повні тести

Фінальний стан лайвкодингу. Він відповідає `solution/`: класифікує помилки,
не виводить секрети та повний об'єкт провайдера й містить повний test suite.

```powershell
# Команди виконуються з кореня репозиторію, де розташований package.json.
yarn vitest run lesson-01-intro/checkpoints/05-errors-tests/tests
```

Очікування: один test file і 14 пройдених тестів.
