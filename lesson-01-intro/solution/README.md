# Lesson 01 — готове рішення

Це завершений консольний застосунок. Він робить один реальний запит через
OpenAI Responses API та друкує відповідь у PowerShell.

## Запуск готового результату

Відкрити PowerShell і виконати:

```powershell
# Команди виконуються з кореня репозиторію, де розташований package.json.
yarn dev:lesson01:solution "Обчисли 37 * 19. Поверни лише число."
```

Перед першим запуском у кореневому `.env` мають бути заповнені
`OPENAI_API_KEY` і `OPENAI_MODEL_FAST`. Повна одноразова підготовка наведена в
[кореневому README практики](../README.md).

Видимий результат — блок `📤 Надіслано`, очікування відповіді, блок
`📝 Відповідь` і рядок `🤖 Фактична модель`. Вебсторінку відкривати не потрібно.

Команду можна виконати й з цієї папки, але її повна назва не змінюється:

```powershell
yarn dev:lesson01:solution "Поясни різницю між let і const одним реченням."
```

## Перевірка коду без реального API

```powershell
# Команди виконуються з кореня репозиторію, де розташований package.json.
yarn check:lesson01:solution
```

Ця команда не використовує API key. Вона запускає статичні перевірки,
14 unit-тестів рішення, checkpoint-тести та production build.

## Що реалізовано

- environment перевіряється через Zod без виведення секретів;
- запит надсилається через `openai.responses.create()`;
- модель береться лише з `OPENAI_MODEL_FAST`;
- `store: false` вимикає зберігання Response для цього запиту;
- timeout дорівнює 30 секундам, автоматичні повтори вимкнені;
- помилки показують безпечний статус і `request_id`, але не API key, headers
  або request body.

Реальний виклик може бути платним. Unit-тести використовують mock-клієнт і не
звертаються до мережі.
