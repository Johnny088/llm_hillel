# Evals у Lesson 01

Окремого eval dataset у першому занятті немає. Готове рішення перевіряється
без мережі командою:

```powershell
# Команди виконуються з кореня репозиторію, де розташований package.json.
yarn check:lesson01:solution
```

Після цього реальна працездатність перевіряється одним CLI-запитом з
[інструкції solution](../README.md). Повноцінний eval harness з'являється в
Lesson 02.
