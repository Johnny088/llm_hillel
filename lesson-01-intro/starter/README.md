# Lesson 01 — завдання для студента

Мета — завершити консольну програму, яка приймає текст із PowerShell, надсилає
один запит до OpenAI та показує відповідь.

## Спочатку подивитися готовий результат

З кореня репозиторію:

```powershell
# Команди виконуються з кореня репозиторію, де розташований package.json.
yarn dev:lesson01:solution "Обчисли 37 * 19. Поверни лише число."
```

Підготовка `.env` і пояснення очікуваного результату наведені в
[кореневому README практики](../README.md).

## Що вже підготовлено

```text
starter/
├── src/cli.ts       # функції з TODO
├── src/index.ts     # запуск CLI та реальний OpenAI client
└── tests/cli.test.ts # 14 тестів-завдань it.todo
```

Незавершений starter може компілюватися, але це ще не означає, що завдання
виконано.

## Послідовність роботи

1. У `src/cli.ts` реалізувати `loadEnvironment()`.
2. Реалізувати `readUserInput()`.
3. Реалізувати безпечне форматування API-помилок.
4. Реалізувати `requestAnswer()` з моделлю з environment і `store: false`.
5. У `tests/cli.test.ts` замінити всі 14 `it.todo` звичайними тестами. Набір має
   покрити всі 14 сценаріїв готового `solution`, зокрема повернення лише
   перевірених env-полів і передачу помилки mock-клієнта вище.
6. Запустити фінальну перевірку starter.

```powershell
yarn check:lesson01
```

Команда навмисно завершується помилкою, доки в тестах лишається хоча б один
`it.todo`. Після реалізації всі перевірки мають пройти.

## Запуск власної реалізації

Після завершення TODO та заповнення кореневого `.env`:

```powershell
yarn dev:lesson01 "Що таке closure у JavaScript? Поясни одним абзацом."
```

Ця команда запускає саме `starter`. Для порівняння готовий варіант завжди
запускається через `yarn dev:lesson01:solution "текст"`.

Unit-тести не повинні звертатися до реального API. Реальний контрольний запит
виконується лише після успішної локальної перевірки й може бути платним.
