# Реєстр когорт курсу (Cohorts Registry)

У цьому каталозі зберігаються конфігурації когорт. Файли `cohort-YYMM.json` є джерелом істини для номера групи, цільового репозиторію, опублікованого заняття та параметрів dev-режиму. Поточні значення дивіться у відповідному JSON; не дублюйте тут лічильники занять, бо вони застарівають після кожного релізу.

## Керування релізом

Зміни спочатку вносяться до основного репозиторію курсу. Перевірте конфігурацію та доступні когорти командами `yarn cohort:list` і `yarn cohort:status --cohort YYMM`, потім перевірте підготовлений реліз командою `yarn cohort:check --cohort YYMM`. Публікуйте заняття з основного репозиторію командою `yarn cohort:release NN --cohort YYMM`.

Не редагуйте клон репозиторію когорти напряму. Реліз у ньому має відтворюватися з основного репозиторію та конфігурації когорти, щоб студентські репозиторії залишалися узгодженими з курсом.

Для синхронізації вже опублікованого рівня використовуйте `yarn cohort:sync --cohort YYMM`.

Якщо публічний `dev/` містить окрему викладацьку реалізацію, синхронізуйте матеріали командою `yarn cohort:sync --cohort 2609 --preserve-dev`. Цей режим зберігає всі файли `dev/`, перевіряє їхні байти та Git-об’єкти перед push і відмовляється працювати, якщо рівень релізу або метадані заняття не збігаються з реєстром. Його не можна поєднувати з переходом на новий рівень через `--release`.
